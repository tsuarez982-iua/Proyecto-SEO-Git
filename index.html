¿Qué es el SEO?

SEO (Search Engine Optimization) es el conjunto de técnicas utilizadas para mejorar el posicionamiento de un sitio web en los motores de búsqueda.

Este proyecto aplica buenas prácticas de SEO On-Page utilizando etiquetas HTML semánticas, metaetiquetas y atributos alt para mejorar la accesibilidad y el posicionamiento en buscadores.

Proyecto realizado con HTML5, CSS3 y GitHub.
